# English Documentation Directory (`docs/en/`)

This directory contains standalone English documentation, design specifications, and guides for the Wallpaper Picker project.

## Directory Structure

- `docs/adr/`: Architecture Decision Records (ADRs). ADRs maintain a bilingual (English & Chinese) side-by-side format within each document and are not separated here.
- `docs/en/`: Standalone English technical documents, implementation guides, and user manuals.
- `docs/zh/`: Standalone Chinese technical documents, implementation guides, and user manuals.
